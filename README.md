GestureControl

GestureControl is an Android application that allows users to control their phone using hand gestures detected through the camera.

Features

- Real-time hand tracking using MediaPipe.
- Camera support using CameraX.
- Move the cursor using hand movements.
- Perform Tap, Drag, and Long Press actions.
- Navigate using Back, Home, and Recent Apps gestures.
- Touch-free phone interaction.

Technologies Used

- Kotlin
- Android Studio
- CameraX
- MediaPipe Hand Landmarker
- Android Accessibility Service

Requirements

- Android 8.0 (API 26) or higher.
- Camera permission.
- Accessibility permission for gesture-based phone control.

Installation

1. Download and install the APK.
2. Allow camera permission.
3. Enable the GestureControl Accessibility Service.
4. Start using hand gestures to control your phone.
